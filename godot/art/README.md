# Character art

Five original astronaut SVGs replace geometric tower bodies. Suit accents and chest
badges retain role recognition. They share proportions, outline weight and palette.
Faces and suits are scalable vector art; runtime motion uses small independent floats.

Alien SVGs and the Earth geography come from this project's Claude browser prototype
(`src/ui/art.js` on `claude/basics`), itself carrying forward the shared v2 artwork.
Earth's expression remains a separate runtime layer so geography can rotate slowly.
No third-party character images or generated bitmap sprites were introduced.
