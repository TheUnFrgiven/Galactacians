# Local assets

All planets, aliens, tower shapes, icons, and interface illustrations in the new game are original SVGs defined in `src/ui/art.js`. The game has no runtime dependency on an image service or CDN.

Nunito is bundled locally as `fonts/Nunito-Variable.ttf`. It was downloaded from the [Google Fonts Nunito repository](https://github.com/google/fonts/tree/main/ofl/nunito). Its SIL Open Font License is included in `fonts/OFL.txt`.

Sound effects are short synthesized Web Audio tones. The sound preference is stored on the device.
